## Skyglim-Resources
Skyglim用のResourcePack<br>
本マップ未プレイの場合、重大なネタバレ及び楽しみを大きく損なわせる場合があります。閲覧等はプレイ後にすることを強く推奨します。これにはResourcePack本体と、github上のIssuesやPRを含みます。
<br><br>
